# ntr-website-grp3

### Belangrijk
In de vuex store, podwalk module is een flag toegevoegd aan de actions genaamd "USE_MOCK_DATA". 
Deze flag en de bijbehorende code die bij elke action uitgevoerd wordt is hier omdat het CMS aan het einde
van de periode down was. Om die reden neemt de code een omweg door data uit de mockData.ts te halen.
Deze flag en code kan weggehaald worden als het CMS naar behoren werkt.
